`foefie new` starts a project: it asks for the org, name, type, Python version, build backend and author, runs `uv init`, lists the folder in `dev.code-workspace` and the README, optionally creates a private GitHub repo (no push), and now also appends the project to `foefie.toml` (created from the bundled example if missing; existing entries are never changed). The wizard lives in its own `foefie.new` module.
